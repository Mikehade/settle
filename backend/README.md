# settle

FastAPI service. Structure and rules: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
Adding Redis, Celery, storage, Docker: [docs/EXTRAS.md](docs/EXTRAS.md).

## Setup

```bash
uv sync                                   # or: python -m venv .venv && pip install -r requirements-dev.txt
cp .env.example .env                      # already created if generated by fastkit; set DATABASE_URL
python manage.py makemigrations "init"
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver                # http://localhost:8000/docs
```

With uv, prefix commands with `uv run` or activate `.venv`.

## Commands

| Command | |
|---|---|
| `python manage.py runserver` | Dev server (reload in development) |
| `python manage.py startapp <domain>` | Generate every layer for a domain and register it |
| `python manage.py makemigrations "<msg>"` | Autogenerate a migration |
| `python manage.py migrate [rev]` / `revert [rev]` | Upgrade (default head) / downgrade (default -1) |
| `python manage.py history` / `current` / `stamp [rev]` | Migration info |
| `python manage.py createsuperuser` / `changepassword` | Users (`SUPERUSER_PASSWORD` env for non-interactive) |
| `python manage.py check` | Settings, app wiring, DB connection, pending migrations |
| `python manage.py routes` | List endpoints |
| `python manage.py shell` | Shell with `container` and `settings` loaded |
| `python manage.py seed` | Run `scripts/seed.py` |
| `python manage.py lint` | ruff + layer contracts (import-linter) |
| `python manage.py export-reqs` | Pin `requirements*.txt` from `uv.lock` |
| `pytest` | Tests (`APP_ENV=test`, in-memory SQLite) |

## Environments

`APP_ENV` selects `src/config/<env>.py`: `development`, `staging`, `production`, `test`.
Environment variables override `.env`, which overrides class defaults.
Production disables `/docs` and logs JSON.
